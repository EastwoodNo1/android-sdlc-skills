# ADLC Docs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship plugin v0.2.0 with the `adlc-docs` skill, the `adlc-documenter` agent and `SessionEnd`/`SessionStart` hooks that capture every session automatically, then adopt it in SuperSnake.

**Architecture:** A harness-neutral core (Bash scripts, Markdown procedure, templates) plus a Claude Code adapter (`agents/`, `hooks/hooks.json`). The hooks stage privacy-filtered session notes in `<git-common-dir>/adlc/`. The main agent folds them into `docs/adlc/` at the next PR.

**Tech Stack:** bash, git, jq, Claude Code CLI 2.1.304 (`claude -p`). The tests are plain bash with a stub `claude` on `PATH`.

**Spec:** `docs/superpowers/specs/2026-10-27-adlc-docs-design.md`

## Global Constraints

- No comments in `*.sh`, `*.yml`, `*.yaml`, `*.toml`, `*.properties` (a shebang is allowed). JSON has none.
- Dependencies: `bash`, `git`, `jq`, the harness CLI. No Python, Node or bats.
- Commits: Conventional, body with `Why:` and `What:`, ending `Co-Authored-By: <model line>`.
- Headless and subagent model: `sonnet`.
- Staging root: `$(git -C "$cwd" rev-parse --path-format=absolute --git-common-dir)/adlc`.
- Loop guard env var: `ADLC_CAPTURE=1`. Per-session off switch: `ADLC_DISABLE=1`. Repo off switch: `<state>/disabled`. Opt-in marker: `<state>/enabled`.
- `SessionEnd` must return in under 1 s. The trivial-session threshold is fewer than 3 human prompts.
- The digest caps each assistant message at 1500 characters and the whole file at 150000 bytes. Human prompts are never dropped.
- Stale lock: 30 minutes. Backfill skips transcripts modified within 10 minutes. `SessionStart` sweep: `--limit 3`. Log retention: the last 50.
- Mechanical redaction replaces with `[redacted]`:
  - emails: `[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}`
  - home paths: `/Users/[^/ ]+` and `/home/[^/ ]+`
  - each line of `<state>/deny-list`, case-insensitive fixed string

## Review Focus

1. A hook started in a repo that is not a git repo (or has no `jq`) must exit 0 silently and never break quitting. Test: `session_end_outside_git_repo_exits_0` in Task 4.
2. Paths with spaces (repo or transcript path) must work. Test: `capture_handles_space_in_repo_path` in Task 5.
3. Two hooks firing at once (end of one session, start of another) must not run two captures. Test: `capture_respects_lock` in Task 5.
4. A transcript with no human prompts but many tool calls (pure automation) is trivial and is skipped. Test: `session_end_skips_tool_only_transcript` in Task 4.
5. A stale lock left by a crashed capture must not block forever. Test: `capture_breaks_stale_lock` in Task 5.

### Task 5: `capture.sh`

**Files:**
- Create: `skills/adlc-docs/scripts/capture.sh`
- Modify: `skills/adlc-docs/tests/run.sh`

**Interfaces:**
- Consumes: `lib.sh`, `digest.sh`, the agent prompt contract (Task 2).
- Produces: `capture.sh <harness> <session_id> <transcript_path> <cwd>`.
  - Exit codes: 0 when captured or skipped, 1 on failure.
  - On success it creates `<state>/staged/<YYYY-MM-DD>-<first 8 of id>.md` (the date from the first transcript timestamp), appends the id to `<state>/captured` and removes `<state>/digests/<id>.md`.
  - It locks with `mkdir <state>/lock`. A held lock exits 0 with a "busy" log line.
  - The runner command (mode `agent`):

    ```
    ADLC_CAPTURE=1 claude -p --agent android-sdlc:adlc-documenter --model sonnet \
      --settings '{"disableAllHooks":true}' --no-session-persistence \
      --permission-mode dontAsk \
      --allowedTools "Read" "Grep" "Glob" "Write(<state>/staged/**)" \
                     "Bash(git log:*)" "Bash(git show:*)" "Bash(gh pr view:*)" "Bash(gh pr list:*)" \
      "<prompt per contract>"
    ```

    It runs with `cwd = toplevel`. `ADLC_CLAUDE_BIN` overrides `claude` for tests. `ADLC_PLUGIN_DIR`, when set, adds `--plugin-dir <dir>` for an unreleased plugin. `ADLC_RUNNER_MODE` comes from Task 1.
  - After the runner it calls `adlc_redact` on the note and fails when the note is missing or empty.
  - It prunes logs beyond 50.

**Interfaces:**
- Consumes: `lib.sh`, `capture.sh`.
- Produces:
  - `backfill.sh [--harness claude] [--project-dir <dir>] [--limit N] [--exclude <session_id>]`:
    - `ADLC_PROJECTS_DIR` (default `~/.claude/projects`) is scanned for folders whose name starts with `slug(toplevel of main worktree)`. The slug replaces every character outside `[A-Za-z0-9]` with `-`.
    - It keeps `*.jsonl` whose first `cwd` equals the main worktree path, starts with it plus `/`, or starts with it plus `-`.
    - It skips files modified within 10 minutes, ids in `captured`, trivial sessions and `--exclude`.
    - It runs oldest first by first timestamp, calling `capture.sh` in the foreground, up to `--limit`.
    - It prints `captured N, skipped M`.
  - `session-start.sh <harness>`, with hook JSON on stdin:
    - exits 0 always and silently unless opted in
    - starts `backfill.sh --limit 3 --exclude <session_id>` detached
    - when `staged/` has N>0 notes, prints exactly `ADLC: N session note(s) waiting for fold-in at the next PR (see android-sdlc:adlc-docs).`
