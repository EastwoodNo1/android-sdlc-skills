# Security policy

## Supported versions

Only the latest release built from `main` is supported.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. This uses GitHub private vulnerability reporting, which is enabled for this repository.

Include what you found, the steps to reproduce it, and the version or commit you tested.
